# Scripts-fix-Nahimic-service-TFT-LoL-Riot-client-fix
Riot_Hosts_Toggle_RU — переключатель записей hosts для обхода проблем с запуском Riot Client и TFT.
Nahimic_TFT_RU — утилита для остановки и запуска службы Nahimic и связанных процессов перед запуском TFT.

============================================================================
## Riot_Hosts_Toggle_RU

Небольшая Windows-утилита для включения и отключения записей `hosts`, которые могут помочь при проблемах с запуском Riot Client и Teamfight Tactics.
Актуально для РФ и интернет провайдеров дом.ру, МТС и других.

## Запуск

Запустите `Riot_Hosts_Toggle.cmd` правой кнопкой мыши → **«Запуск от имени администратора»**. Без повышенных прав скрипт только покажет инструкцию и не изменит систему.

## Возможности

- включает шесть заданных записей Riot в отдельном помеченном блоке `hosts`;
- отключает только этот блок, не изменяя остальные пользовательские записи;
- показывает текущий статус обхода в верхней части меню;
- сохраняет резервную копию `hosts` перед каждым фактическим изменением.

## Примечания

Скрипт использует встроенный PowerShell Windows, не скачивает файлы и не выполняет сетевые запросы. Это неофициальное решение: используйте его на свой риск и отключайте, когда оно больше не требуется.

============================================================================
## Nahimic_TFT_RU

Windows-утилита для остановки и запуска службы Nahimic и связанных с ней процессов. Может быть полезна, если Nahimic мешает запуску или работе Teamfight Tactics.

## Запуск

Запустите `Nahimic_TFT_RU.cmd` правой кнопкой мыши → **«Запуск от имени администратора»**. Скрипт проверяет наличие повышенных прав и не выполняет действий без них.

## Возможности

- фиксит работу клиента TFT на Windows, когда после загрузки игры бесконечная загрузка или чёрный экран.
- показывает текущее состояние службы `NahimicService`;
- останавливает службу и завершает процессы `Nahimic3`, `NahimicSvc64`, `NahimicSvc32` и `NahimicAPO4Volume`;
- повторно проверяет, не остались ли процессы активными;
- запускает службу Nahimic и проверяет результат.

## Использование

1. Выберите `1`, чтобы остановить Nahimic перед запуском Riot Client или TFT.
2. Запустите игру вручную.
3. После игры выберите `2`, чтобы снова включить Nahimic.

## Примечания

Скрипт меняет состояние системной службы и завершает процессы. Если Nahimic нужен для звука, микрофона или эффектов вашего устройства, включите его обратно после игры.
